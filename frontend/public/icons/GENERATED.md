# Additional matrix domain icons

Created with the built-in image generation tool using `heart.png` as a style reference.
Original twelve PNGs and source Downloads assets are unchanged. The three new
transparent PNGs are used directly as app icons, without a CSS background or crop.

## blood.png

Use case: stylized-concept. Edit the reference icon into a matching new sibling icon for the Well Ahead health app. Reference is the existing glossy rounded-square heart icon. Preserve precisely its front-facing squircle geometry, scale, beveled edges, soft rim lighting, glossy translucent dimensional materials, subtle shadow and the large transparent margin: squircle occupies roughly x=140..880 y=150..870 in a 1024x1024 square. Change ONLY the interior motif and tile color. New motif: one pearl-white sculpted blood droplet with a small curved leaf integrated beside it, representing blood and nutrition. Tile palette: ruby and coral red. Center motif at identical apparent scale. No text, no labels, no badge, no heart/ECG symbol, no extra tile around it. Export actual transparent RGBA background outside the rounded square, with shadow preserved, not a white canvas or checkerboard. Target 1024x1024. Save as distinct output; do not overwrite reference.
