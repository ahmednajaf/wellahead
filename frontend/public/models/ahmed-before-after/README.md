# Whole Person comparison assets

`before.glb` and `after.glb` are browser exports of the user-supplied
`Ahmed-Before-After/ahmed-reference-before.blend` and
`Ahmed-Before-After/ahmed-reference-after.blend` files. Each is approximately
3.6 MB and contains the actual distinct geometry, face textures, clothing,
UVs and complexion/grooming vertex colours. These are illustrations of Ahmed,
not generated likenesses of each app user or predictions of health outcomes.
No health-profile or recommendation data changes the meshes.

Exports bake the supplied active reference shape keys and pose, apply world
transforms, and embed textures. The studio floor, camera, lights, armature and
unused animations are omitted. The source files in Downloads are never saved
or modified. Only the two browser-ready exports are included in this repository.
